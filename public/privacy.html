Data & privacy

Privacy notice

Last updated: 27 September 2026

In short

  • No account, no cookies, no ads, no trackers, no third-party scripts.
  • Your IP address is used in the server’s memory to keep the game running and protected from abuse. It is never saved.
  • Names, cards and votes exist in memory only while their room is open.
  • We count visitors and games as totals, and the totals are all we keep.

01Who runs this site

sealthebunker.com is a free, non-commercial hobby project run by a private individual, @dolgikhog on GitHub. That person is the controller of the data described here.

Questions about privacy: privacy@sealthebunker.com, or an issue on GitHub. GitHub issues are public, so use email for anything personal.

02What is processed, and why

Your IP address and browser details

As with any website, every request brings your IP address and your browser’s user-agent string to the server. The game uses the IP address to cap how many connections, rooms and failed attempts (such as wrong room codes) one network gets, which protects it from abuse and overload.

Kept
In memory only, while your connection or your room lasts (a count of failed attempts: at most about ten minutes after the last one). The web server keeps no access logs, and its error lines leave the IP address out (see “Error logs”).

Visit counts

Each time the game page loads, the server adds to the day’s totals: a page view, whether the link was an invite to a room, and the site that linked here if your browser says so (its domain only, such as google.com). Crawlers and scripts are counted as a number only.

To count how many different people visit per day, the server makes a one-way hash of your IP address and user agent, salted with a random key that is replaced every day. The key and the hashes stay in memory, cannot be turned back into an address, and are thrown away when the day ends. Only the day’s total is saved.

Kept
Hashes: in memory, until the end of the day. Daily totals: 400 days, after which they only add to all-time totals.

Game statistics

Totals only, such as rooms created, games started and finished, players per game, the share of English and Russian, and the day’s highest number of connections and of games at the same time. No names, no addresses, no room codes, no game content.

Kept
Daily totals: 400 days, after which they only add to all-time totals.

What you type and play

The display name you choose, your cards, your votes and the game log are held in the server’s memory to run the game, and the other people in your room see them. Nothing asks for your real name: a nickname is fine.

Kept
In memory only. A room and everything in it is deleted at the latest 30 minutes after the last person leaves, or when the server restarts.

Error logs

When something breaks, the game server writes a technical message to the system log: program errors, and lines about rooms such as “room ABCD deleted (idle)”. These never contain IP addresses, names or game content.

The web server in front of the game (Caddy) keeps no access logs. When a request fails there, for example in the few seconds the game restarts for an update, it writes an error line with the requested web address (which may contain a room code) and technical details such as the error and its duration. The IP address and everything your browser sent with the request (user-agent, languages, referring site) are removed before the line is written.

Kept
Until the system log’s rotation removes them (the log’s size is capped).

03What stays on your device

The site keeps a few entries in your browser’s localStorage and sessionStorage: a token that puts you back in your seat after a reload, the name you last used, your language, your narrator and display settings, and notes that the game briefing and a narration were already shown, so they are not repeated. They stay on your device and go to the server only when the game needs them, for example the token when you rejoin your room. There are no cookies. To remove the entries, clear this site’s data in your browser.

04Other services

  • Hosting. Hetzner Online GmbH runs the server in Germany (EU), as a processor on our behalf. The data above does not leave the EU.
  • HTTPS. The web server, Caddy, uses certificates from Let’s Encrypt. No visitor data goes to them.
  • GitHub. “Report an issue” and “Suggest an idea” open GitHub (GitHub, Inc., USA), a separate service with its own privacy statement. The form comes prefilled with the game version, a short browser summary such as “Firefox 131 · Linux”, your language and, in a room, the room code. GitHub receives these when the link opens; they become public only if you submit the issue.
  • Google Search Console. We use it to see how the site appears in Google Search. It adds no script and no cookie to this site: Google collects that data on its own search pages, under its own privacy policy.

Nobody else gets data from this site. Nothing is sold, and there is no profiling or automated decision-making.

05Legal basis

Legitimate interests (Art. 6(1)(f) GDPR): running the game, keeping it secure and fair, and knowing roughly how many people use it. The entries on your device are strictly necessary for features you ask for, so they need no consent (Art. 5(3) of the ePrivacy Directive, 2002/58/EC). With no cookies and no tracking, there is nothing to consent to.

06Your rights

Under the GDPR you may ask for access to your data, its correction or erasure, and restriction of its processing, and you may object to the processing. You can also complain to a data protection authority, for example in the EU country where you live or work.

In practice almost nothing stored here identifies you, so there is usually nothing to look up or delete: game data disappears with its room, error lines with the log’s rotation, and the entries on your device are yours to clear. Questions: privacy@sealthebunker.com.

07Changes

If the site starts handling data differently, this page and the date at the top are updated at the same time.

02Что обрабатывается и зачем

IP-адрес и данные браузера

Как и на любом сайте, с каждым запросом сервер получает твой IP-адрес и строку user-agent браузера. По IP-адресу игра ограничивает, сколько подключений, комнат и неудачных попыток (например, неверных кодов комнат) приходится на одну сеть, — это защищает её от злоупотреблений и перегрузки.

Хранится
Только в памяти, пока открыто подключение или существует комната (счётчик неудачных попыток — не дольше примерно десяти минут после последней). Журналов доступа веб-сервер не ведёт, а из строк журнала ошибок IP-адрес удаляется (см. «Журнал ошибок»).

Счётчик посещений

Каждый раз, когда загружается страница игры, сервер прибавляет к итогам дня: просмотр страницы, была ли это ссылка-приглашение в комнату, и сайт, откуда ведёт ссылка, если браузер его сообщает (только домен, например google.com). Поисковые роботы и скрипты учитываются только общим числом.

Чтобы понять, сколько разных людей заходит за день, сервер вычисляет необратимый хеш от IP-адреса и user-agent с «солью» — случайным ключом, который каждый день заменяется новым. Ключ и хеши хранятся только в памяти, восстановить по ним адрес нельзя, а в конце дня они удаляются. Сохраняется только итоговое число за день.

Хранится
Хеши — в памяти, до конца дня. Итоги по дням — 400 дней, потом они только добавляются к итогам за всё время.

Статистика игр

Только суммы: например, сколько создано комнат, начато и доиграно игр, сколько игроков в игре, доля английского и русского и наибольшее за день число подключений и игр одновременно. Ни имён, ни адресов, ни кодов комнат, ни содержимого игр.

Хранится
Итоги по дням — 400 дней, потом они только добавляются к итогам за всё время.

Что ты вводишь и как играешь

Выбранное имя, твои карты, голоса и журнал игры хранятся в памяти сервера, чтобы вести игру, и их видят остальные в комнате. Настоящее имя нигде не требуется — подойдёт любой ник.

Хранится
Только в памяти. Комната со всем содержимым удаляется не позже чем через 30 минут после того, как из неё выходит последний человек, или при перезапуске сервера.

Журнал ошибок

Если что-то ломается, игровой сервер пишет техническое сообщение в системный журнал: ошибки программы и строки о комнатах вроде «room ABCD deleted (idle)». IP-адресов, имён и содержимого игр в них нет.

Веб-сервер перед игрой (Caddy) журналов доступа не ведёт. Если запрос на нём не удался — например, в те несколько секунд, пока игра перезапускается при обновлении, — он пишет строку в журнал ошибок: адрес страницы (в нём может быть код комнаты) и технические подробности, например ошибку и её длительность. IP-адрес и всё, что браузер отправил вместе с запросом (user-agent, языки, сайт, с которого ты пришёл), удаляются до записи.

Хранится
Пока записи не удалит ротация системного журнала (его размер ограничен).

03Что хранится на твоём устройстве

Сайт записывает несколько значений в localStorage и sessionStorage браузера: токен, по которому после перезагрузки ты возвращаешься на своё место, последнее введённое имя, язык, настройки рассказчика и отображения, а также отметки о том, что вводный экран и озвучка уже показаны, чтобы они не повторялись. Они остаются на устройстве и уходят на сервер, только когда это нужно игре, — например, токен, когда ты возвращаешься в комнату. Файлов cookie нет. Чтобы удалить эти значения, очисти данные этого сайта в браузере.

Больше никто данных с этого сайта не получает. Мы ничего не продаём, не строим профилей и не принимаем автоматических решений.

05Правовые основания

Законный интерес (ст. 6(1)(f) GDPR): чтобы игра работала, была защищена и честна и чтобы примерно знать, сколько людей в неё играет. Значения на твоём устройстве строго необходимы для функций, которыми ты пользуешься, поэтому согласия не требуют (ст. 5(3) Директивы ePrivacy, 2002/58/EC). Раз нет ни cookie, ни слежки, соглашаться не на что.

06Твои права

По GDPR ты можешь запросить доступ к своим данным, их исправление, удаление и ограничение обработки, а также возразить против обработки. Можно и пожаловаться в надзорный орган по защите данных — например, в стране ЕС, где ты живёшь или работаешь.

На деле здесь почти не хранится ничего, что тебя идентифицирует, поэтому искать и удалять обычно нечего: данные игры исчезают вместе с комнатой, строки журнала ошибок — при его ротации, а значения на устройстве можно стереть в любой момент. Вопросы — на privacy@sealthebunker.com.
